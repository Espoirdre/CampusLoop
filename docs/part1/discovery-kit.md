# 客户访谈工具包 · Part 1

> 用途：11/26 提交前，完成 **至少 2 位真实用户** 的访谈，其中 **至少 1 位不是本班同学**。
> 这一部分是作业里唯一标注 **NO AI** 的硬性要求，AI 代写、AI 角色扮演、队友充当用户，都不计入。
> 你只需要带这份东西去聊 10 分钟，回来把结果贴进报告第 3 行。

---

## 一、先明确三条红线

| 红线 | 具体含义 |
|---|---|
| **不能只找同学** | 至少 1 位必须是"不在本班"的人。宿管阿姨、食堂阿姨、图书馆管理员、外院同学，都算 |
| **不能问态度** | "你觉得这个有用吗"→ 无效证据。"你上次丢东西是什么时候、当时怎么找的"→ 有效证据 |
| **不能留个人信息** | 不记姓名、微信、电话、学号，不录音不录像。只用 P1 / P2 这样的代号 |

作业原话：

> A compliment or "I would use it" alone is weak evidence.

也就是说，"挺好的""我会用"这类回答本身没有价值。有价值的是**具体发生过的事**：时间、动作、花了多久、花了多少钱、最后结果。

---

## 二、访谈前：口头知情说明（照着念一遍就行）

> 我们在做一个课程项目，想了解一下大家在校园里找东西、处理闲置的真实经历。大概占用你 8 分钟可以吗？
> 我只记匿名笔记，不记你的名字和联系方式，也不会录音。你不想回答的问题可以直接跳过，随时可以停。

对方同意 → 开始问。对方犹豫 → 换人，不要勉强。

## 三、A 组：访谈宿管 / 楼管 / 值班室（捡到东西的一方）

**谁去**：陈思峥（主问）+ 高斌雄（记录）
**去哪**：宿舍楼值班室、教学楼值班室、图书馆服务台 —— 任选一个，最好是你自己楼的
**为什么优先这个**：他们是"东西最终流向的地方"，手里有真实数字，而且**天然不是本班同学**

### 问题顺序（按这个顺序问，不要跳）

1. 最近一次有同学来问"有没有人捡到东西"，是什么时候？
2. 那次丢的是什么？后来怎么处理的？
3. 现在捡到的东西一般放哪儿？会不会登记？登记在纸上还是本子上？
4. 这个学期大概收了多少件？最后有多少没人来领？
5. 同学一般怎么知道东西在你这儿？（群里问 / 贴条 / 直接上门）
6. 有没有东西放太久，最后只能上交或者扔掉的？大概多久会处理一次？
7. 有没有遇到过认领时出问题的情况？（比如两个人抢同一件、说不清是什么东西）
8. 如果有人能在手机上搜到"最近收到了哪些东西"，你觉得会改变什么？**会带来什么麻烦？**

> 第 8 题的后半句很关键。问"会带来什么麻烦"能逼出真实顾虑（隐私、冒领、有人天天来问），比问"好不好"有用得多。

### 记录要点

- 数字最重要：「一学期 60 多件」「只有十几个被领走」——这种直接写进报告
- 记原话，不要转述成书面语
- 记下他提到的**现有流程**：登记本、抽屉、上交周期

## 四、B 组：访谈非本班同学（丢东西 / 买二手的一方）

**谁去**：嵇翰林（主问）+ 马桢豪（记录）
**找谁**：别的学院/别的专业的同学、社团认识的人、老乡 —— **只要不是这门课的**
**千万别找**：本组 5 人、本班同学（只能作为补充，不能算作那"至少一位"）

### 问题顺序

**第一部分：丢东西（占 5 分钟）**

1. 你上一次丢东西是什么时候？丢的是什么？
2. 发现丢了之后，你做的**第一件事**是什么？然后呢？
3. 你发在哪些群里？发了之后有人回吗？大概多久有人回？
4. 找回来了吗？从丢到找到（或放弃）隔了多久？
5. 有没有去问过宿管 / 服务台 / 教学楼值班室？为什么去 / 为什么没去？
6. 这次大概损失多少？（钱，或者重新买、补办花了多久）

**第二部分：买二手（占 3 分钟）**

7. 你上一次买二手教材 / 闲置是什么时候？买的什么？
8. 那次是怎么找到卖家的？怎么完成交易的（见面 / 快递 / 放门口）？
9. 整个过程里最麻烦的一步是哪一步？

**第三部分：如果有个能搜的地方**

10. 如果要搜，你会先搜什么词？（看他会不会用"校园卡"还是"一卡通"——这决定搜索框怎么设计）
11. 什么东西会让你不敢用？（怕对方是骗子 / 怕要加微信 / 怕信息被别人看到）

### 追加追问（对方回答含糊时用）

| 他说 | 你追问 |
|---|---|
| "就在群里问了一下" | 哪个群？几个人在的群？问完有人理你吗？ |
| "后来找到了" | 怎么找到的？谁告诉你的？隔了多久？ |
| "挺麻烦的" | 具体哪一步麻烦？花了多长时间？ |
| "应该有用吧" | 你上次遇到这事的时候，如果有这个东西，你会先做什么？ |

## 五、回来填这张表（直接对应报告第 3 行）

每位被访者填一行。**只填代号，不填姓名以外的任何个人信息。**

```
代号：P1
日期：2026-11-__
场景/背景：（谁、在哪、什么情况）
是否本班：out-of-class / in-class
谁去谈的：（组员姓名）
具体证据（原话或数字）：
  + 支持我们判断的部分：
  − 挑战我们判断的部分：
```

### 填完自查

- [ ] 至少 2 位，且至少 1 位是 out-of-class
- [ ] 每行都有**具体数字或原话**，没有"他觉得不错"这类话
- [ ] 没有出现真实姓名、微信、电话、学号
- [ ] 至少有一条是**挑战**我们的（如果全是支持，说明问题问偏了，回去补一个"什么情况下你不会用"）

## 六、访谈完必须做的判断

报告第 3 行最后要写团队结论，三选一：

| 结论 | 什么情况下选 |
|---|---|
| **proceed** | 至少 2 人都描述过真实发生过的问题，且现有办法确实不好用 |
| **revise** | 有人提到的问题和我们想的不一样（比如大家其实更在意"二手"，不在意"失物"）→ 写清改了什么 |
| **need-more-evidence** | 说法互相矛盾，或都只能说"应该有用" → 写清下一步问谁 |

不要因为想显得顺利就硬写 proceed。作业原文明确写了：

> Weak or negative evidence is useful when it changes a decision.

**一条真实的负面发现，比五条"挺好的"更能得分。**
