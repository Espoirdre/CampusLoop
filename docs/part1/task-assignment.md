## 一、为什么这么切

| 常见切法 | 问题 |
|---|---|
| 两人一组去访谈 | 要凑两个人的时间，一个人有事整组停摆 |
| 谁有空谁写报告 | 五个人改同一个文件，互相覆盖 |
| 一起等素材齐了再剪辑 | 剪辑的人干等，最后压到截止前两小时 |

**这次的切法：**

1. **一个访谈一个人去**（不组队 → 不需要约两个人的时间）
2. **每人写自己那张卡**（不改报告、不改别人的内容 → 零冲突）
3. **汇总只发生一次、时间固定**（12:00 收卡，18:00 合并，来晚的直接不要）
4. **只有 20 分钟需要全员同时在场**（拍视频），其余所有事各干各的
