## 问这 6 个（按顺序）

1. 你上一次丢东西是什么时候？丢的是什么？
2. 发现丢了之后，你做的**第一件事**是什么？然后呢？
3. 你发在哪些群里？发了之后有人回吗？大概多久？
4. 找回来了吗？从丢到找到（或放弃）隔了多久？
5. 有没有去问过宿管 / 服务台 / 教学楼值班室？为什么去 / 为什么没去？
6. 你上一次买二手教材或闲置是什么时候？怎么找到卖家的？最麻烦的一步是哪一步？
